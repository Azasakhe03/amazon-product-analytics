
## Amazon Product Intelligence

Developed by AG Smart Analytics.

This project transforms raw Amazon product datasets into structured, analysis-ready data and generates insights into product pricing, discounts, ratings and categories.

### Features

- Automated data cleaning and preparation
- Data quality validation
- Unique record identification
- Product pricing analysis
- Discount analysis
- Category-level performance analysis
- Top-rated product identification
- Automated Markdown and CSV reports

### Technologies

- Python
- Pandas
- Tabulate
- Power BI (planned)

### Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

### Workflow

1. Place the original dataset in `data/raw/amazon.csv`.
2. Run the cleaning script.
3. Run the analytics script.
4. Review the generated reports in the reports folder.
